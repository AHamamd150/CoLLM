## Common Terminal Errors and Fixes

### NameError: name 'X' is not defined
**Terminal:**
```
File "analysis.py", line 35, in main
    obj_mask = (pt > PT_CUT) & (np.abs(eta) < ETA_CUT)
NameError: name 'PT_CUT' is not defined
```
**Fix:** Define the variable before use:
```python
PT_CUT = 20.0  # Add this BEFORE line 35
ETA_CUT = 2.4
obj_mask = (pt > PT_CUT) & (np.abs(eta) < ETA_CUT)
```

### AttributeError: no field named 'mass'
**Terminal:**
```
File "analysis.py", line 59, in main
    invariant_mass = (p1 + p2).mass
AttributeError: no field named 'mass'. Did you mean: 'mask'?
```
**Fix:** Ensure vector.zip() was used (not ak.zip()) and vector.register_awkward() was called:
```python
vector.register_awkward()  # Must be at top after imports

vec = vector.zip({  # NOT ak.zip()
    "pt": pt,
    "eta": eta,
    "phi": phi,
    "mass": ak.ones_like(pt) * 0.000511
})
```

### TypeError: Field elements must be 2- or 3-tuples
**Terminal:**
```
File "analysis.py", line 20, in main
    data = tree.arrays(selected_branches)
TypeError: Field elements must be 2- or 3-tuples, got 'Electron/Electron.PT'
```
**Fix:** Add `library="ak"` parameter:
```python
data = tree.arrays(selected_branches, library="ak")  # Add library="ak"
```

### IndexError: index out of bounds
**Terminal:**
```
File "analysis.py", line 50, in main
    leading_pt = pt[:, 0]
IndexError: index 0 is out of bounds for axis 1 with size 0
```
**Fix:** Ensure multiplicity cut was applied first:
```python
# Apply multiplicity cut BEFORE accessing by index
n_particles = ak.num(pt)
event_mask = (n_particles == 2)
pt = pt[event_mask]
# NOW safe to access pt[:, 0]
leading_pt = pt[:, 0]
```

### ValueError: cannot convert awkward array to numpy
**Terminal:**
```
File "analysis.py", line 70, in main
    plt.hist(ak.to_numpy(eta), bins=50)
ValueError: cannot convert to NumPy (jagged array)
```
**Fix:** Flatten jagged arrays before converting:
```python
plt.hist(ak.to_numpy(ak.flatten(eta)), bins=50)  # Add ak.flatten()
```
